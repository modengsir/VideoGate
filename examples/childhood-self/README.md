# Demo 001 · 《小时候的我 × 现在的我》

本案例是 ModengSir 在 2026 年进行的 AI 视频预审实测**文字复盘**，不包含未授权原图、人脸或服务账单。两道前置审核结果来自原测试记录；视频完成后的检测曾用于原文章，但 **VideoGate V0.1 不执行该功能**。

## 故事与计划

15 秒，16:9。左侧1990年代老房子里的5岁女孩，右侧现代客厅里的成年自己。女孩问：“长大以后，你过上想要的生活了吗？”成年人回答：“过上了，有点想你。”女孩轻碰脸颊：“那你要多笑笑呀。”

| 阶段 | 实测摘要 | 处理 |
|---|---|---|
| Gate 1 | 8 项：4项 P0 FAIL、3项 UNVERIFIED、1项纸面 PASS | 统一人物发型、延长对白时段、删走位、修冲突 |
| Gate 2 初审 | 3项 PASS、5项 UNVERIFIED | 补人物原图和手/脸局部参考 |
| Gate 2 补件复审 | 发现1项 P0：开场左右像同一个房间 | 强化左右独立背景、增加柔和光缝 |

**不能把阶段性审查结果累加为节省的视频生成次数。** 缺少实际 H3 成本与对照实验，所以不报告节省金额。初审/复审的检查口径不完全相同，也不应当被当作严格的逐项转化漏斗。
