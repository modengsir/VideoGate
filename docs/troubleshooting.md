# 常见问题

**Agent 没发现 Skill**：确认安装的是 Agent 所支持目录、对应项目已经在工作区中打开；重启/重新加载 Agent，明确说“调用 video-gate Skill”。一些产品版本不支持原生 Skills，应改为复制通用 Prompt。

**Windows 没有 python3**：使用 `py -3 scripts/install.py ...`，或直接复制 `.agents/skills/video-gate/` 到文档指定的目录。

**第二关没有看到图**：不要假装通过；请换具备图像能力的模型、启用相关输入，或者提交原始图片文件。

**Ling 只能提交一张图**：参考 `prompts/single-image.md` 拼高清编号对照图，手、脸太小时提交单独局部裁剪图。

**提示词里 `@Image1` 顺序变了**：以实际平台生成的引用编号为准更新映射。不要猜平台自动编号和本地文件名一致。

**P0 一直无法消除**：逐条处理“原始证据—修改方案—修改后证据”，避免直接把所有素材重做。可记录创作者承担的残余风险，但报告不能自动把 P0 设成 PASS。

**为什么不检查成片**：项目特意只覆盖生成前的两关。最终视频和音频必须由创作者在外部进行验收。
