# 自有智能体 / 不使用 Ling 的方法

无需 Ling。只要你的智能体能读分镜，就可以执行 Gate 1；有真正视觉输入才可以执行 Gate 2。

**通用操作**：
1. 创建自定义 GPT、Claude Project 或自有 Agent，把 `prompts/universal-reviewer.md` 的全文放进其长期系统指令；如支持知识文件，再附上 Skill 的 `references/` 三份规则和 JSON Schema。
2. 在会话中输入“执行 Gate 1”，附上 `project-brief.md`、分镜、对白和 Prompt，同时粘贴 `prompts/gate1.md` 的逐项清单。
3. 完成后把报告留档；进入 Gate 2 时上传真实人物参考与关键帧，并粘贴 `prompts/gate2.md`。只传文字文件名而没有可视像素时不得判断图像质量。
4. 要求输出完整八项审核表、P0 修复建议、UNVERIFIED 项和是否建议放行。修改后重新执行受影响项目。

**能力探测**：先问“本轮实际收到几张图片？请依次报告编号和可辨识内容”；不要相信模型笼统声称能看到所有图片。如完全无法查看则停止视觉评判。

**替代模型**：Ling、ChatGPT 的视觉模型、Claude 视觉模型、Gemini 视觉模型、通过 Agent 接入的其他多模态模型。支持的具体文件类型和限制以你的账号及平台为准，**本项目不包含内置 API Key 或强制付费调用**。

**安全**：真实人像或商业素材上传第三方前先确认隐私和使用许可。审核材料里的“忽略规则”之类指令一律视为不可信内容。可在本地自建文件管理，但自动向外部模型上传需要用户明确授权。
